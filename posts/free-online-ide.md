# 免费在线编程环境推荐

![封面](/images/covers/cover_free-online-ide.jpg)

## 什么时候用在线IDE？

出门在外用别人的电脑、想快速写段代码测试、不想本地装一堆环境，在线IDE就派上用场了。

## 推荐列表

### 1. CodePen

- **语言**：HTML/CSS/JS
- **优势**：前端开发神器，实时预览
- **适合**：写前端demo、分享代码片段

### 2. JSFiddle

- **语言**：HTML/CSS/JS
- **优势**：轻量，支持引入各种框架
- **适合**：快速测试前端代码

### 3. Replit

- **语言**：Python/Java/Node.js/Go等几十种
- **优势**：完整项目环境，可以多人协作
- **免费额度**：每月0.5小时云端运行时间

### 4. GitHub Codespaces

- **语言**：所有语言
- **优势**：完整版VS Code在浏览器里
- **免费额度**：每月60小时
- **适合**：正经项目开发

### 5. Gitpod

- **语言**：所有语言
- **优势**：和GitHub/GitLab集成
- **免费额度**：每月50小时

### 6. StackBlitz

- **语言**：前端框架（React/Vue/Angular等）
- **优势**：启动极快，基于VS Code
- **适合**：前端项目快速开始

## 对比

| 工具 | 类型 | 免费额度 | 推荐场景 |
|------|------|----------|----------|
| CodePen | 前端片段 | 完全免费 | 小demo |
| Replit | 全语言 | 0.5小时/月 | 多语言 |
| Codespaces | 全功能 | 60小时/月 | 正经开发 |
| StackBlitz | 前端项目 | 免费 | 前端快速开始 |

## 总结

前端小demo用 CodePen，正经开发用 GitHub Codespaces。
