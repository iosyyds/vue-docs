# 8 个在线渐变配色网站：设计不缺颜色

这篇整理实用内容，都是平时做设计总结的经验。

## 总结

内容基于公开资料整理，适合日常设计工作参考。

## 8 个在线渐变配色网站

### 1. uiGradients

**网址**：uigradients.com
**特点**：最经典的渐变网站
**推荐**：每天一个新配色

### 2. Gradient Hunt

**网址**：gradienthunt.com
**特点**：设计师分享
**推荐**：分类搜

### 3. Coolors

**网址**：coolors.co
**特点**：随机配色方案
**推荐**：按空格换配色

### 4. Color Hunt

**网址**：colorhunt.co
**特点**：精选配色
**推荐**：热门配色

### 5. Web Gradients

**网址**：webgradients.com
**特点**：柔和渐变
**推荐**：背景用

### 6. CSS Gradient

**网址**：cssgradient.io
**特点**：在线调渐变
**推荐**：自己调

### 7. Grabient

**网址**：grabient.com
**特点**：简洁现代
**推荐**：UI 设计用

### 8. Brand Colors

**网址**：brandcolors.net
**特点**：知名品牌配色
**推荐**：参考大牌

## 使用技巧

1. **渐变别太花**：两种颜色就够
2. **同色系渐变**：最安全
3. **低饱和度**：高级感
4. **加蒙版**：让渐变有过渡

## 小结

配色不用想破头，这些网站直接抄。
