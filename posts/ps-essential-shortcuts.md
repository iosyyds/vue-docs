# PS 必知 20 个快捷键：效率翻倍从键盘开始

PS 有几百个快捷键，没人全背下来。但日常修图设计，有 20 个用得最多，记住就够了。

## 基础操作

| 快捷键 | 功能 | 使用场景 |
|--------|------|---------|
| `Ctrl + J` | 复制图层 | 修图前复制原图，不破坏原片 |
| `Ctrl + Shift + N` | 新建图层 | 每次调整都新建图层，方便改 |
| `Ctrl + G` | 图层编组 | 把同类图层放一个组里 |
| `Ctrl + E` | 合并图层 | 合并选中的图层 |
| `Ctrl + Shift + E` | 合并可见图层 | 把所有可见图层合并 |
| `Ctrl + Z` | 撤销 | 后悔药 |
| `Ctrl + Shift + Z` | 重做 | 撤销多了按这个 |

## 选择和移动

| 快捷键 | 功能 | 使用场景 |
|--------|------|---------|
| `V` | 移动工具 | 切换到移动工具 |
| `M` | 选框工具 | 矩形/椭圆选区 |
| `L` | 套索工具 | 自由选区 |
| `W` | 快速选择 | 自动识别边缘 |
| `Ctrl + D` | 取消选区 | 选完了取消 |
| `Ctrl + Shift + I` | 反选 | 选了背景，反选就是主体 |

## 画笔和橡皮擦

| 快捷键 | 功能 | 使用场景 |
|--------|------|---------|
| `B` | 画笔工具 | 画画/蒙版 |
| `E` | 橡皮擦 | 擦除 |
| `[` / `]` | 缩小/放大画笔 | 调画笔大小 |
| `Shift + [` / `Shift + ]` | 降低/提高硬度 | 调画笔软硬 |

## 视图和缩放

| 快捷键 | 功能 | 使用场景 |
|--------|------|---------|
| `Ctrl + +` | 放大 | 看细节 |
| `Ctrl + -` | 缩小 | 看整体 |
| `Ctrl + 0` | 适合屏幕 | 一键适配窗口 |
| `空格 + 拖拽` | 抓手工具 | 平移画布 |

## 实用技巧

1. **按住 Alt 点图层蒙版**：查看蒙版黑白区域
2. **按住 Ctrl 点图层缩略图**：载入选区
3. **双击图层缩略图**：快速改图层名
4. **Alt + 滚轮**：缩放画布

## 小结

不用全背，用多了自然记住。先把 `Ctrl+J`、`V`、`B`、`[` `]`、`Ctrl+Z` 这几个用熟，其他遇到再查。
