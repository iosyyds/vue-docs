# 个人博客域名怎么选：便宜好记优先，备案问题怎么绕

域名是博客的门面。选对后缀、理解备案规则，后面少很多麻烦。

## 一、后缀怎么选

| 后缀 | 价格（首年） | 适合 |
|------|-------------|------|
| .com | 55-70 元 | 首选，最通用 |
| .cn | 20-30 元 | 国内，需备案 |
| .top / .xyz / .icu | 首年 9-15 元 | 便宜但容易被识别成垃圾站 |
| .dev / .app | 100+ 元 | 技术博客，Google 系 |
| .me | 80+ 元 | 个人博客，有个性 |

个人博客建议：**.com 优先**，预算有限 .top/.xyz 也行，别买太冷门的后缀（.club/.work 容易进垃圾邮件列表）。

## 二、备案是什么

备案 = 域名在工信部登记，只有**域名指向国内服务器/CDN**才需要。

- 博客挂 GitHub Pages（美国）→ **不需要备案**
- 博客挂腾讯云/阿里云国内服务器 → **必须备案**（不然 80 端口被封）
- 用国内 CDN（腾讯云/阿里云 CDN）→ **必须备案**

不备案也能玩：GitHub Pages / Vercel / Cloudflare Pages 都是国外服务，域名直接用，不用备案。代价是国内访问慢。

## 三、Cloudflare 域名的常见坑

很多人把域名放在 Cloudflare（NS 切到 CF），方便用 CF CDN。注意：

1. **CF 免费版国内不 BGP**：橙云模式国内访问 CF 节点（香港/洛杉矶），比直连 GitHub 稳但不是极速
2. **CF 不提供备案**：想绑国内 CDN 必须先在国内备案
3. **DNS only vs Proxied**：灰云只解析，橙云走 CDN，两个模式 IP 不一样

## 四、域名注册商选谁

- **Namesilo / Porkbun**：便宜，无隐私保护费，支持支付宝
- **阿里云/腾讯云**：贵但中文后台，备案方便
- **Cloudflare Registrar**：成本价续费，需要域名先转入 CF

个人推荐：便宜域名在 Namesilo/Porkbun，需要备案的在阿里云（备案流程顺）。

## 五、小技巧

1. **抢短域名**：4 字母 .com 早没了，5 字母组合还能淘
2. **别用数字+特殊字符**：口语传播难记
3. **WHOIS 隐私保护**：开了，别让域名暴露你的邮箱
4. **域名邮箱**：用 Cloudflare Email Routing 免费开 `you@你的域名` 转发到 Gmail

## 小结

域名选个好记的 .com，挂国外服务不用备案，想国内快再考虑备案 + 国内 CDN。别在域名上纠结太久，内容才是核心。
