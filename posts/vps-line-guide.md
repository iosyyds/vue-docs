# VPS 选购避坑：CN2、9929、GIA 都是什么

买 VPS 时最常见的困惑：都是 2 核 2G、30 美元一年，为什么有的晚高峰卡成 PPT，有的丝滑得像国内机房？差别不在配置，在**线路**。

这篇用尽量直白的语言讲清楚几个高频名词，以及不同用途该怎么选。

![不同回国线路的路径差异](/images/tutorial/vps-line-1.svg)

## 一、先理解为什么会有延迟差别

数据从海外机房回国，要经过海底光缆和国内骨干网。普通线路走的是「公共互联网」，晚高峰大家一起挤，丢包率能到 20%。优质线路走的是运营商专线（如 CN2），相当于高速专用车道。

延迟本身不是最大问题（150ms 也能用），**丢包和抖动**才是体验杀手。

## 二、CN2 的两种档次

CN2（China Telecom Next Carrying Network）是中国电信的优质承载网，但内部也有等级：

**CN2 GT（Global Transit）**

- 出口走 CN2，但国内段仍可能走普通 163 骨干
- 晚高峰会拥堵，丢包明显
- 价格中等，适合轻量建站

**CN2 GIA（Global Internet Access）**

- 全程走 CN2，包括国内段
- 晚高峰依然稳定，丢包率通常低于 1%
- 价格贵，通常是 GT 的 1.5~3 倍

判断方法：看商家标注。写「CN2 GIA」的才是全程 GIA；只写「CN2」多半是 GT 或混合。

## 三、联通 9929 和移动 CMI

除了电信 CN2，另外两家也有优质线路：

- **联通 9929（AS9929）**：联通精品网，北方联通用户延迟低、稳定
- **移动 CMI（AS58453）**：移动国际线路，移动宽带用户友好

很多商家卖的是「三网优化」：电信走 CN2、联通走 9929、移动走 CMI。这类机器价格高于单网优化，但对全国用户都友好。

**注意**：你的宽带运营商决定了实际体验。电信用户买联通优化机器，好线路也用不上。

## 四、按用途选机器

| 用途 | 推荐配置 | 线路要求 |
|---|---|---|
| 个人博客（静态） | 1 核 512M~1G | 普通线路够用，配 CDN 更好 |
| WordPress / Typecho | 1~2 核 1~2G | 普通线路 + CDN，或 CN2 GT |
| 自建服务（RSSHub、监控） | 1 核 1G | 普通线路 |
| 远程开发 / SSH 频繁操作 | 2 核 2G | CN2 GIA 或 9929，延迟敏感 |
| 视频/大流量代理类 | 视流量 | 优质线路，注意合规 |
| 数据库/API 服务 | 2 核 4G | 稳定优先，GIA 或三网优化 |

个人博客这类静态站点，**CDN 的作用远大于线路**：Cloudflare 或国内 CDN 把静态资源缓存到边缘，源站线路差一点用户也感觉不到。

## 五、除了线路还要看什么

**超售比**。同样配置，邻居都在跑满 CPU，你的机器也会卡。看商家口碑里的「超售」评价，比看参数重要。

**流量和带宽**。标注「1Gbps 端口 / 每月 1TB 流量」的是共享带宽；标注「不限流量」的通常有限速条款。

**IP 质量**。部分 IP 段被墙或被标记为滥用，买之前问商家能否换 IP、是否额外收费。

**备份与快照**。支持免费快照的商家，误操作时能救命。

**支付方式**。支持支付宝的商家对国内用户友好，退换货政策也要看清。

## 六、几个避坑提醒

- **超低价年付要谨慎**：9.9 美元一年的机器，跑路风险高于性价比收益
- **别迷信「原生 IP」**：多数场景不需要，价格却贵不少
- **先月付试用**：线路体验受时间段影响，至少测一个晚高峰再决定年付
- **测速方法**：从国内多地 ping + traceroute，看回程是否绕路
- **不要把所有服务放一台机器**：博客、数据库、备份至少分两处

## 七、简单测试命令

买到机器后先测：

```bash
# 回程路由（看是否绕路）
traceroute -n 你的本地IP

# 下载速度
curl -o /dev/null -w "%{speed_download}\n" http://speedtest.example.com/100MB.zip

# 磁盘 IO
dd if=/dev/zero of=test bs=64k count=16k conv=fdatasync
```

晚高峰（20:00~23:00）再测一次，才能看出真实水平。

选 VPS 的核心不是「买最贵的」，而是「匹配用途」：静态博客把钱花在 CDN 上，远程开发把钱花在线路上，数据库把钱花在稳定性和备份上。想清楚这一点，就不容易被参数表忽悠。
