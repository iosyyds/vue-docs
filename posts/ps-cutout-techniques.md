# PS 抠图技巧大全：什么图用什么方法

这篇整理实用内容，都是平时做设计总结的经验。

## 总结

内容基于公开资料整理，适合日常设计工作参考。

## 什么时候用什么方法

抠图不是一个方法走天下。背景越复杂，方法越复杂。

### 1. 魔棒工具（W）— 简单背景

**适用**：纯色背景、颜色单一的图

**步骤**：
1. 按 `W` 选魔棒
2. 点背景
3. Shift 加选没选中的地方
4. `Ctrl+Shift+I` 反选就是主体

**缺点**：边缘锯齿，不适合毛发

### 2. 快速选择工具 — 半复杂背景

**适用**：背景有渐变但主体清晰

**步骤**：
1. 按 `W` 选快速选择
2. 在主体上拖拽
3. Alt 减选多选的地方
4. 属性栏点"选择并遮住"细化边缘

### 3. 钢笔工具 — 精确抠图

**适用**：产品图、Logo、需要干净边缘

**步骤**：
1. 按 `P` 选钢笔
2. 沿边缘点点点
3. 闭合路径后 `Ctrl+Enter` 转选区
4. `Ctrl+J` 复制出来

**优点**：边缘最干净
**缺点**：慢，需要练

### 4. 选择主体 — AI 自动

**适用**：主体清晰、背景不复杂

**步骤**：
1. 菜单：选择 → 主体
2. PS 自动识别主体
3. 进"选择并遮住" refine

### 5. 选择并遮住 — 毛发抠图

**适用**：头发、毛绒、动物毛

**步骤**：
1. 先用快速选择大概选中
2. 点"选择并遮住"
3. 用边缘调整画笔在头发上涂
4. 输出到带蒙版的图层

### 6. 通道抠图 — 复杂毛发

**适用**：烟花、烟雾、头发细丝

**步骤**：
1. 进通道面板
2. 找对比最强的通道复制
3. Ctrl+I 反相
4. 画笔把主体涂白、背景涂黑
5. Ctrl 点通道缩略图载入选区
6. 回到图层面板复制出来

## 速查表

| 图片类型 | 推荐方法 |
|---------|---------|
| 纯色背景 | 魔棒 |
| 产品图 | 钢笔 |
| 人像头发 | 选择并遮住 |
| 烟花烟雾 | 通道 |
| 主体清晰 | 选择主体 |
| 半复杂背景 | 快速选择 |

## 小结

先试最简单的方法，不行再升级。大多数情况"选择主体 + 选择并遮住"就够了。
