# 免费CDN加速服务推荐：让你的网站快一倍

![封面](/images/covers/cover_free-cdn.jpg)

## 什么是CDN？

CDN（内容分发网络）把你的静态资源缓存到全球各地的节点，用户访问时从最近的节点读取，速度提升明显。

## 推荐列表

### 1. Cloudflare CDN

- **费用**：完全免费
- **节点**：全球300+城市
- **优势**：自带WAF、DDoS防护、免费SSL
- **缺点**：免费版国内速度一般

### 2. jsDelivr

- **费用**：完全免费
- **用途**：JS/CSS/图片等静态资源
- **优势**：国内有节点，速度快
- **用法**：`https://cdn.jsdelivr.net/gh/用户名/仓库@分支/文件路径`

### 3. Statically

- **费用**：免费
- **优势**：支持GitHub/GitLab/WordPress
- **用法**：`https://cdn.statically.io/gh/用户名/仓库/分支/文件`

### 4. 又拍云

- **费用**：新用户免费15GB/月
- **优势**：国内速度快
- **缺点**：需要实名认证

## 选择建议

| 场景 | 推荐 |
|------|------|
| 整站加速 | Cloudflare |
| JS/CSS加速 | jsDelivr |
| 国内访问 | 又拍云/七牛云 |

## 总结

Cloudflare 是最全面的免费CDN，jsDelivr 适合加速 GitHub 上的静态资源。
