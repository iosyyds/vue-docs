# 免费在线协作工具推荐

![封面](/images/covers/cover_free-collab.jpg)

## 前言

不管是和朋友一起做项目，还是团队写文档，在线协作工具都能提升效率。整理几个免费好用的。

## 文档协作

### 1. 飞书文档

- **费用**：个人版完全免费
- **优势**：支持实时协作、思维导图、多维表格
- **适合**：中文团队

### 2. Notion

- **费用**：个人免费版
- **优势**：all-in-one，数据库、文档、看板
- **缺点**：国内访问偶尔慢

### 3. 腾讯文档

- **费用**：免费
- **优势**：微信生态无缝，支持在线表格
- **适合**：快速收集信息

## 设计协作

### 4. Figma

- **费用**：免费版3个项目
- **优势**：UI设计行业标准，实时协作
- **适合**：界面设计

### 5. Excalidraw

- **费用**：完全免费开源
- **优势**：手绘风格图表，实时协作
- **适合**：画架构图、流程图

## 项目管理

### 6. Trello

- **费用**：免费版10个看板
- **优势**：看板式任务管理，简单直观

### 7. Linear

- **费用**：免费版最多2500issue
- **优势**：界面漂亮，开发团队友好

## 选择建议

| 场景 | 推荐 |
|------|------|
| 中文团队文档 | 飞书 |
| 个人知识库 | Notion |
| UI设计 | Figma |
| 流程图 | Excalidraw |
| 任务管理 | Trello/Linear |

## 总结

免费版对个人和小团队完全够用，飞书在国内体验最好。
