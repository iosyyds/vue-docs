# PS 合成技巧：怎么把两张图融在一起

这篇整理实用内容，都是平时做设计总结的经验。

## 总结

内容基于公开资料整理，适合日常设计工作参考。

## 合成最常见的问题

两张图拼在一起，一眼就假。问题出在三个地方：光影不统一、色调不统一、边缘不自然。

## 1. 光影统一

**原则**：主光源方向要一致

**做法**：
1. 先找参考图的光源方向（看高光和阴影在哪边）
2. 把要合成的图旋转到同方向
3. 用曲线压暗暗部，提亮高光
4. 加投影：新图层画黑色软边投影

## 2. 色调统一

**原则**：两张图颜色要像在同一个环境

**做法**：
1. 调整图层 → 颜色匹配
2. 选择参考图作为源
3. 微调亮度和颜色强度

**手动调**：
- 照片滤镜：加参考图的色调
- 可选颜色：统一红黄绿色偏

## 3. 边缘处理

**原则**：不要有硬边

**做法**：
1. 给图层加蒙版
2. 选软边黑色画笔
3. 把边缘擦掉一点，让两张图融合
4. 不透明度 30%，慢慢擦

## 4. 细节统一

1. **加颗粒**：滤镜 → 杂色 → 添加杂色，数量 5%，统一颗粒
2. **加暗角**：四周压暗
3. **色温统一**：参考图偏暖就都加暖色

## 实战例子：人放进场景

1. 抠出人物
2. 放进场景图
3. 调整大小和位置
4. 匹配光影方向
5. 加颜色匹配
6. 脚下画投影
7. 加整体调色层

## 常见穿帮

- 人物亮，背景暗 → 人物太亮
- 人物影子朝左，背景光源在右 → 光源矛盾
- 边缘一圈白边 → 没擦干净

## 小结

合成就是让两张图看起来像一张图。关键在光影、色调、边缘三点统一。
