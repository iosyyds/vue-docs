# PS 三种磨皮方法对比：哪种最好用

这篇整理实用内容，都是平时做设计总结的经验。

## 总结

内容基于公开资料整理，适合日常设计工作参考。

## 三种磨皮方法对比

### 1. 表面模糊磨皮（最简单）

**步骤**：
1. 复制图层
2. 滤镜 → 模糊 → 表面模糊
3. 半径：5~10 像素
4. 阈值：10~20 色阶
5. 加黑色蒙版，白画笔涂皮肤

**优点**：快，5 分钟搞定
**缺点**：会丢失纹理，适合快速出图

### 2. 高低频磨皮（最专业）

**步骤**：
1. 复制两次图层
2. 下层：高斯模糊半径 3 像素
3. 上层：图像 → 应用图像（反相，混合模式：相加，缩放 2，补偿值 128）
4. 上层混合模式改"线性光"
5. 下层模糊层磨皮，上层保留纹理

**优点**：保留皮肤纹理
**缺点**：步骤多，新手容易晕

### 3. Portraiture 插件（最省事）

**步骤**：
1. 滤镜 → Imagenomic → Portraiture
2. 自动识别肤色
3. 调磨皮程度：20~40%
4. 点确定

**优点**：一键磨皮，效果好
**缺点**：要付费

## 怎么选

| 场景 | 推荐方法 |
|-----|---------|
| 快速修图 | 表面模糊 |
| 商业精修 | 高低频 |
| 人像写真 | Portraiture |
| 学生党 | 表面模糊免费 |

## 磨皮注意事项

1. **别磨到眼睛眉毛**：这些要锐利
2. **保留毛孔纹理**：磨皮过度像塑料
3. **鼻翼嘴角别磨**：这些地方结构要保留
4. **随时对比**：按住 Alt 点蒙版看黑白

## 小结

新手先用表面模糊练手，熟练了学高低频。磨皮不是越光滑越好，自然最重要。
