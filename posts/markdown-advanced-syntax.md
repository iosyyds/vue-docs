# Markdown 进阶语法：表格、脚注、任务列表你都会用吗

![Markdown 语法](https://images.unsplash.com/photo-1633356122102-3fe601e05bd2?w=800&h=400&fit=crop)

大多数人用 Markdown 只会标题、列表、加粗。其实它还有很多进阶语法，写文档和博客更专业。

## 表格对齐

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 内容 | 内容 | 内容 |
```

冒号在哪边就对齐哪边。

## 任务列表

```markdown
- [x] 已经写完的文章
- [x] 已经部署的主题
- [ ] 还没做的友链检测
- [ ] 还没做的 RSS 优化
```

GitHub 和 VitePress 都支持，勾选框能点击。

## 脚注

```markdown
这是一段话[^1]，后面有注释。

[^1]: 这是脚注内容，点击可跳转。
```

写技术文档引用来源时特别好用。

## 高亮文本

```markdown
==这段文字高亮显示==
```

支持的渲染器会显示黄色背景。

## 代码块指定语言

```javascript
function hello() {
  console.log("你好");
}
```

指定语言后自动语法高亮。

## 数学公式

```
行内公式：$E = mc^2$

块级公式：
$$
\int_0^\infty e^{-x^2} dx = \frac{\sqrt{\pi}}{2}
$$
```

VitePress 装了 KaTeX 插件就能渲染。

## 折叠块

```markdown
<details>
<summary>点击展开</summary>

这里是隐藏内容。
</details>
```

长文档不想全展开时用。

## 插入图片并控制大小

```markdown
![描述](图片链接 =400x300)
```

等号后面指定宽高，解决图片太大撑爆页面。

## 小结

基础语法人人会，进阶语法才拉开差距。常用的就是表格、任务列表、脚注、代码高亮这几个，写博客和文档时随手用上。
