# VS Code 必备插件推荐：装完这 10 个效率翻倍


VS Code 裸装就是个文本编辑器，装对插件才是 IDE。这篇整理前端开发真正用得上的 10 个。

## 1. Prettier — 代码格式化

保存自动格式化，团队代码风格统一。装完在设置里开 `formatOnSave: true`。

## 2. ESLint — 代码检查

实时标红语法错误和不规范写法，比肉眼找快 10 倍。

## 3. GitLens — Git 增强

每行代码旁边显示最后修改人和时间，看历史 blame 超方便。

## 4. Error Lens — 错误内联显示

把 ESLint/TS 的错误直接显示在代码行后面，不用翻 Problems 面板。

## 5. Material Icon Theme — 文件图标

不同文件类型不同颜色图标，文件树一眼认出来。

## 6. Volar — Vue 3 支持

Vue 3 开发必装，语法高亮 + 智能提示 + 类型检查。

## 7. Tailwind CSS IntelliSense — Tailwind 提示

写 Tailwind 类名自动补全，不用记类名。

## 8. Better Comments — 彩色注释

`// TODO` 橙色、`// !` 红色、`// ?` 蓝色，注释分类一目了然。

## 9. Turbo Console Log — 快速打 log

选中变量按快捷键自动插入 `console.log(变量)`，调试神器。

## 10. Settings Sync — 配置同步

把插件列表和设置同步到 GitHub，换电脑一键恢复。

## 别装太多

插件装多了 VS Code 启动慢、占内存。原则：
- 每个插件都要日常用得上
- 同类功能只留一个（比如格式化只留 Prettier）
- 三个月没用过的插件直接卸

## 小结

这 10 个装完，VS Code 就是个完整的前端 IDE。别追求插件数量，够用就行。
