# PS 文字特效：5 个超实用效果

这篇整理实用内容，都是平时做设计总结的经验。

## 总结

内容基于公开资料整理，适合日常设计工作参考。

## 5 个常用文字效果

### 1. 金属字

**步骤**：
1. 打字，选粗黑体
2. 图层样式 → 渐变叠加：从黑到灰到白
3. 斜面和浮雕：深度 100%，大小 5 像素
4. 光泽：角度 120 度，距离 10 像素

**适合**：海报标题、Banner

### 2. 渐变字

**步骤**：
1. 打字
2. 图层样式 → 渐变叠加
3. 选渐变色：比如从紫到粉
4. 角度 90 度

**技巧**：可以用渐变映射代替，更方便改色

### 3. 立体字

**步骤**：
1. 打字
2. 图层样式 → 斜面和浮雕
3. 样式：内斜面
4. 深度：200%
5. 大小：10 像素
6. 角度：120 度

**适合**：3D 海报、活动标题

### 4. 霓虹字

**步骤**：
1. 打字，颜色选深色背景
2. 图层样式 → 外发光
3. 发光颜色：荧光色（粉/绿/蓝）
4. 大小：20 像素
5. 不透明度：75%

**技巧**：加内发光效果更真实

### 5. 手写字

**步骤**：
1. 找手写字体（比如方正字迹）
2. 打字
3. 加轻微投影
4. 加一点纹理叠加

**适合**：生活方式、文艺类设计

## 通用技巧

1. **字体别超过两种**：一个标题字体，一个正文字体
2. **字间距微调**：大标题字间距拉开点
3. **对齐**：左对齐比居中更专业
4. **层级**：标题大、副标题小、正文最小

## 小结

文字效果不用记参数，自己调着玩。多做几个就有感觉了。
