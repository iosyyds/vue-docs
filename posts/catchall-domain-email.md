# 域名邮箱 Catch-all：一个域名无限别名

注册一个小网站时留了常用邮箱，两年后开始收到各种营销邮件，却不知道是哪个网站泄露的。想用「邮箱别名」隔离，又不想为每个别名单独建账号。

域名邮箱的 **Catch-all** 功能可以解决：只要发往 `*@yourdomain.com` 的邮件，全部投递到你的主邮箱，不需要为每个前缀创建账号。

![Catch-all 的收信路由](/images/tutorial/catchall-1.svg)

## 一、前提条件

- 一个自己的域名（已备案不影响收信）
- 一个支持 Catch-all 的邮件服务
- 域名的 DNS 管理权限

常见选择：

| 服务 | Catch-all | 免费额度 | 备注 |
|---|---|---|---|
| Cloudflare Email Routing | 支持 | 免费 | 只转发，不存储 |
| 网易域名邮箱 | 支持 | 免费版有限 | 国内访问稳定 |
| 腾讯企业邮 | 支持 | 免费版有用户数限制 | 需要企业认证 |
| 自建 Postfix | 支持 | 自己维护 | 灵活但门槛高 |

个人博客最省事的是 **Cloudflare Email Routing**：免费、无需自建、配置十分钟。

## 二、Cloudflare Email Routing 配置

1. 域名已在 Cloudflare 托管
2. 控制台 → **Email → Email Routing** → 启用
3. 添加目标地址（你的真实邮箱），完成验证
4. 开启 **Catch-all**：
   - Custom address：`*`（匹配任意前缀）
   - Action：Send to → 你的真实邮箱

之后 `anything@yourdomain.com` 都能收到，全部转发到真实邮箱。

DNS 方面 Cloudflare 会自动添加 MX 和 TXT 记录，不用手动配。

![Cloudflare 邮件路由的转发链路](/images/tutorial/catchall-2.svg)

## 三、用别名隔离注册来源

Catch-all 的真正价值是「按网站生成别名」：

```
github@yourdomain.com        → 注册 GitHub
taobao@yourdomain.com        → 注册淘宝
bank@yourdomain.com          → 银行
newsletter@yourdomain.com    → 订阅邮件
```

规则很简单：**网站名 + @域名**。好处：

- 某个网站泄露，邮件只到你的一个别名，容易识别
- 收到垃圾邮件可以直接屏蔽该别名
- 不需要提前创建账号，随用随发

在邮箱客户端里建过滤规则：

```
收件人包含 "taobao@" → 自动归档到「购物」文件夹
收件人包含 "newsletter@" → 标记为已读，不提醒
```

## 四、发信怎么办

Cloudflare Email Routing **只支持收信**，不能发信。如果需要用别名发信：

- 在 Gmail 里添加「其他邮箱」为发信地址（需要 SMTP 服务器）
- 用网易/腾讯企业邮的别名功能（支持收发）
- 自建邮件服务器（不推荐，发信信誉难养）

多数场景下只需要收信，比如注册验证、找回密码，这已经覆盖 90% 的需求。

## 五、安全与反垃圾

Catch-all 有一个副作用：**任何前缀都能收信，垃圾邮件也会进来**。因为垃圾发送者会随机猜测前缀。

缓解措施：

- 开启邮件服务的反垃圾（Cloudflare 有基础过滤，网易/腾讯更强）
- 不要用 `admin@`、`info@` 这种常见前缀注册敏感服务
- 定期清理：把长期没用的别名在邮件规则里直接丢弃
- 重要账号（银行、域名注册商）用独立别名，不要和普通注册混用

## 六、迁移现有账号

已经有几十个网站绑定了旧邮箱，不必立刻全改：

1. 先在域名邮箱里建好主账号，测试收发正常
2. 新注册的网站优先用域名别名
3. 重要账号（支付、域名、服务器）逐个在设置里改邮箱
4. 旧邮箱保留至少半年，作为过渡期的找回渠道

## 七、常见问题

**收不到验证邮件**。检查 MX 记录是否生效（`dig MX yourdomain.com`），部分服务的验证邮件会进垃圾箱。

**转发被拒**。Cloudflare 对转发有速率限制，短时间大量邮件可能被拒，正常个人使用不会触发。

**别名被别人猜到**。Catch-all 不提供隐私保护，别名本身就是明文。敏感服务不要依赖别名隐藏身份。

域名邮箱的意义是把「邮箱」从服务商的账号变成自己的资产。换服务商时，域名不变，所有别名继续有效，不用再通知一圈人改地址。
