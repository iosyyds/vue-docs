# PS 人像精修完整流程：从磨皮到调色

人像修图不是随便磨个皮就行，有标准流程。这篇从原片到成片走一遍。

## 第一步：基础调整

1. **Camera Raw 初调**
   - 曝光：拉到脸不黑
   - 对比度：+10~20
   - 高光：-20（压暗过曝）
   - 阴影：+20（提亮暗部）
   - 白色：-10
   - 黑色：+10

2. **裁剪构图**
   - 按 `C` 裁剪
   - 人脸放三分线交点

## 第二步：皮肤处理

1. **高低频磨皮**
   - 复制图层两次（Ctrl+J 两次）
   - 下层：滤镜 → 模糊 → 高斯模糊（半径 3~5 像素）
   - 上层：图像 → 应用图像
   - 上层混合模式改"线性光"
   - 用画笔在下层模糊层磨皮

2. **污点修复**
   - 按 `J` 选污点修复画笔
   - 点掉痘痘、斑、痣

## 第三步：五官调整

1. **液化**
   - 滤镜 → 液化
   - 瘦脸：用向前变形工具推
   - 大眼：用膨胀工具点眼球
   - 隆鼻：推鼻梁
   - 注意别推变形

2. **五官精修**
   - 眼睛：复制眼睛图层，提亮
   - 眉毛：加深眉尾
   - 嘴唇：加唇色

## 第四步：色彩调整

1. **肤色统一**
   - 曲线：红通道微调
   - 色相/饱和度：黄色饱和度 -10

2. **整体调色**
   - 照片滤镜：暖色 85 浓度 10%
   - 可选颜色：红色加一点黄

3. **明暗对比**
   - 曲线：拉 S 形（上提高光，下压暗部）

## 第五步：锐化导出

1. **智能锐化**
   - 滤镜 → 锐化 → 智能锐化
   - 数量：50~80%
   - 半径：1~1.5 像素

2. **导出**
   - Ctrl+Shift+S
   - 格式：JPEG
   - 品质：80~90

## 常见问题

- **磨皮过头**：脸像塑料，保留皮肤纹理
- **液化太狠**：背景歪了，注意背景直线
- **颜色发灰**：加对比，曲线拉 S 形

## 小结

人像精修就是：基础调整 → 皮肤 → 五官 → 调色 → 锐化。每一步都新建图层，方便回头改。
