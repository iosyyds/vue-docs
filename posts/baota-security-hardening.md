# 宝塔面板安全加固清单：这 8 项必须先做

宝塔的便利性背后是默认配置的宽松：面板端口固定、SSH 开放密码登录、数据库监听所有网卡。服务器刚上线的那几天，是扫描器最密集的时候。

下面 8 项按优先级排列，前 4 项建议在网站上线前就完成。

![宝塔安全加固的优先级分层](/images/tutorial/baota-security-1.svg)

## 一、改掉面板默认入口

宝塔默认使用 `8888` 端口 + `/` 路径，扫描器字典里都有。操作：

面板设置 → **面板端口** 改成 5 位数随机端口（如 `28473`）→ **安全入口** 改成随机字符串（如 `/xkbk-9f3a`）。

改完后访问地址变成 `https://服务器IP:28473/xkbk-9f3a`。同时 **开启面板 SSL**，避免登录密码明文传输。

记得在云厂商安全组和服务器防火墙里放行新端口，再关闭旧端口，否则会把自己锁在外面。

## 二、SSH 改密钥登录，禁用密码

密码登录是爆破重灾区。操作：

```bash
# 1. 本地生成密钥（如果还没有）
ssh-keygen -t ed25519 -C "server"

# 2. 把公钥传到服务器
ssh-copy-id -i ~/.ssh/id_ed25519.pub root@服务器IP

# 3. 确认能免密登录后，改服务器配置
sed -i 's/^#*PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sed -i 's/^#*PermitRootLogin.*/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config
systemctl restart sshd
```

**先验证密钥能登录，再禁用密码**，顺序反了会直接失联。

## 三、数据库只监听本机

MySQL 默认监听 `0.0.0.0:3306`，等于把数据库直接摆在公网上。操作：

宝塔 → 数据库 → 配置修改，把 `bind-address = 0.0.0.0` 改为 `bind-address = 127.0.0.1`，保存后重启 MySQL。

如果确实需要远程连接，用 SSH 隧道而不是开放端口：

```bash
ssh -L 3306:127.0.0.1:3306 root@服务器IP
```

本地连 `127.0.0.1:3306` 即可，流量全程加密。

## 四、防火墙只放行必要端口

宝塔 → 安全 → 防火墙，默认只留：

- `22`（或改过的 SSH 端口）
- `80`、`443`
- 面板端口

其余一律删除。云厂商安全组做同样的收紧。Redis、MongoDB、Docker API 这些端口**绝对不要**对公网开放。

![必要端口与禁止暴露端口对照](/images/tutorial/baota-security-2.svg)

## 五、给面板加二次验证

面板设置 → 开启 **两步验证**，绑定 Google Authenticator 或微信小程序。即使密码泄露，没有动态码也进不来。

## 六、网站目录权限收紧

默认 `www` 用户对站点目录有读写权限，某些情况下上传目录可执行 PHP。操作：

- 站点目录权限设为 `755`，属主 `www:www`
- 上传目录（如 `uploads`）关闭 PHP 执行：

```nginx
location ~* /uploads/.*\.php$ {
    deny all;
}
```

- 关闭目录列表：`autoindex off;`

## 七、安装防爆破与 WAF

宝塔软件商店里有 **Nginx 防火墙**（免费版够用），开启：

- CC 防护（防高频请求）
- 恶意 IP 拉黑
- 地区限制（如果访客只在国内，可屏蔽高风险地区）

日志里出现大量 404 扫描请求是正常现象，重点是拦住高频 403/401 尝试。

## 八、备份与恢复演练

安全加固不能只防入侵，还要能兜底：

- 宝塔 → 计划任务 → 每天自动备份**网站 + 数据库**到对象存储（七牛/阿里云 OSS）
- 保留 7 天以上，异地存一份
- **每季度真恢复一次**：把备份下载到本地，在测试目录完整还原

没做过恢复演练的备份，只能叫「以为有备份」。

## 日常检查清单

每周花五分钟看三样东西：

1. 面板 → 安全 → 登录日志，有没有陌生 IP
2. 网站访问日志里 404/403 的 TOP IP
3. 计划任务是否都成功执行

服务器的安全不是装个软件就完事，而是把默认的宽松配置一项项收紧。上面 8 项做完，能挡掉 99% 的自动化扫描。
