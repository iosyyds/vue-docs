# PS 蒙版入门： nondestructive 编辑的核心

这篇整理实用内容，都是平时做设计总结的经验。

## 总结

内容基于公开资料整理，适合日常设计工作参考。

## 蒙版是 PS 最重要的概念

蒙版学好了，PS 就算入门了。蒙版就是"擦了可以擦回来"的橡皮擦。

## 什么是蒙版

- 白色：完全显示
- 黑色：完全隐藏
- 灰色：半透明

**核心**：蒙版不是删除，是隐藏。随时可以改回来。

## 怎么加蒙版

1. 选中图层
2. 点图层面板底部的"添加图层蒙版"按钮（矩形中间有个圆）
3. 图层后面多了个白色方块，就是蒙版

## 画笔涂蒙版

1. 选画笔工具（B）
2. 前景色选黑色（D 恢复默认）
3. 在蒙版上涂，涂到的地方就隐藏了
4. 换成白色涂，又显示出来

## 实战：换背景

1. 抠出人物
2. 放背景图层下面
3. 给人物图层加蒙版
4. 用黑色软边画笔涂边缘，让头发和背景融合

## 实战：局部调色

1. 加曲线调整层
2. 调整层自带蒙版
3. 按 Ctrl+I 反相，蒙版全黑
4. 用白色画笔在要调色的地方涂

## 实战：局部磨皮

1. 复制图层磨皮
2. 加黑色蒙版
3. 用白色画笔在皮肤上涂
4. 眼睛眉毛不涂，保持锐利

## 技巧

1. **按住 Alt 点蒙版**：查看蒙版黑白区域
2. **按住 Shift 点蒙版**：启用/停用蒙版
3. **Ctrl 点蒙版缩略图**：载入选区
4. **画笔硬度 0**：边缘自然

## 为什么用蒙版不用橡皮擦

| 橡皮擦 | 蒙版 |
|-------|------|
| 真删了 | 只是隐藏 |
| 删错了回不来 | 随时改回来 |
| 破坏性编辑 | 非破坏性 |

## 小结

蒙版就是可逆的橡皮擦。养成用蒙版的习惯，修图才专业。
