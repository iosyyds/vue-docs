# 快速上手

本节将介绍如何使用 Vite 创建一个 Vue 项目。

## 环境准备

请确保已安装最新版本的 [Node.js](https://nodejs.org/)（建议 18.0+）。

## 创建项目

```sh
npm create vue@latest my-vue-app
cd my-vue-app
npm install
npm run dev
```

## 项目结构

```
my-vue-app/
├── public/
├── src/
│   ├── assets/
│   ├── components/
│   ├── App.vue
│   └── main.js
├── index.html
└── package.json
```
